# boilerplate

Universal, project-independent development foundation bootstrap.

This repository starts with governance and machine-readable development controls only. No application feature, framework, language, package manager, build system, or deployment model is assumed.

Execution order: DISCOVER -> AUDIT -> MODEL -> PLAN -> APPROVE -> EXECUTE -> VERIFY -> REPORT -> STATE UPDATE.

See docs/DEVELOPMENT_FOUNDATION.md and .foundation/manifest.json for the human-readable guide and machine-readable registry.
